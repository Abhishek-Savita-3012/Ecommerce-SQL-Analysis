# Ecommerce-SQL-Project

## 📌 Project Overview

This project focuses on performing **SQL-based data analysis** on an Ecommerce database using **MySQL**. The objective is to extract meaningful business insights from structured data using SQL queries.

The analysis covers revenue, profit, orders, products, customer sessions, traffic sources, conversion rates, landing pages, refunds, and database optimization.

---

## 🎯 Objective

To use SQL queries to extract, manipulate, and analyze Ecommerce data for business decision-making.

## 🔍 Analysis Performed

The project includes SQL queries to analyze various aspects of Ecommerce business performance:

### 🛒 Product Analysis
- View all available products
- Calculate units sold by product
- Analyze revenue generated by each product
- Identify products with revenue above average order value

### 💰 Revenue & Profit Analysis
- Calculate total revenue
- Calculate total profit
- Find average order value (AOV)
- Analyze monthly revenue trends

### 📦 Order Analysis
- Count total orders
- Filter orders above a specified value
- Analyze orders by device type

### 🌐 Website & Traffic Analysis
- Analyze website sessions by traffic source
- Evaluate conversion rate by device type
- Evaluate conversion rate by marketing campaign
- Identify top-performing landing pages

### 🔄 Customer Behavior Analysis
- Compare new vs repeat visitor sessions
- Analyze customer engagement patterns

### 💸 Refund Analysis
- Calculate total refund amount
- Analyze refunds by product

### ⚙️ Database Optimization & Reporting
- Create analytical views for reporting
- Implement indexes to improve query performance

---

## 📊 Key Business Insights

- Revenue and profit analysis provides a clear understanding of overall business performance and profitability.
- Product-wise revenue analysis helps identify top-performing products and their contribution to total sales.
- Monthly revenue trend analysis enables tracking of business growth and seasonal performance patterns.
- Device-type analysis helps understand customer purchasing behavior across desktop and mobile platforms.
- Traffic source analysis evaluates the effectiveness of different marketing channels in driving website visits.
- Conversion rate analysis measures how efficiently website sessions are converted into customer orders.
- Refund analysis highlights products with higher refund rates, helping identify potential quality or customer satisfaction issues.
- Landing page analysis identifies the most visited entry pages and their impact on user engagement.
- New vs. repeat visitor analysis provides insights into customer retention and loyalty trends.
